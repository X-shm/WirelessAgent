【P3 一、服务异常故障复盘】
- 现象：用户发消息后返回「服务异常: {具体原因}」
- 根因：Kimi K2.6 生成回复过程中，流式请求被中途中止
       （Request was aborted）
- 诱因：
  · Gateway 内存泄漏（182M → 393M，两周翻倍）
  · Kimi API 间歇性抖动
  · 大 prompt（约 9996 token，含系统提示词 + 历史消息）
- 修复：openclaw_client.py 的 chat_stream 加自动重试
       （输出 token 前失败即重试一次，缓解抖动）

------------------------------------------------------------

【P4 二、前端「对话 / 工作」分区改版】
- 背景：React 源码已丢失，基于反美化后的构建产物增量开发，
        后端不改动
- 布局：侧边栏顶部新增「对话 / 工作」切换
  · 对话模式 = 原聊天（新对话 + 历史会话列表）
  · 工作模式 = 工具列表
- 工作模式三个工具：
  · 标准检索  → GET  /rag/search
  · 文件上传  → POST /files/upload
  · 习题解答  → 跳转对话 + 预填题目
- 新增 /work 路由

------------------------------------------------------------

【P5 二、技术要点（续）】
- 预填机制：仅「习题解答」跳转后的对话生效，普通对话不预填
- 复用现有能力：401 自动登出、SSE 流式、KaTeX 公式渲染
- 部署流程：esbuild 重新压缩 → SFTP 上传 → 重启服务
