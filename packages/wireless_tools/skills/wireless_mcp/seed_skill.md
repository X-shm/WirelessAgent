# Wireless Toolbox MCP 使用规则

当问题要求计算、查表、编码、调制、信道或无线网络参数时，调用 MCP 工具并以实际返回值作答。理论解释题先判断是否需要数值；没有必要时不调用工具。

1. 先确定领域：LTE、5G NR、WLAN、蓝牙、通用通信、无线网络、工作流。根据工具描述选择最具体的工具；相近名称不能凭字面猜用途。
2. 调用前读取该工具的 inputSchema。只传 schema 定义的字段，保留原参数名、数据类型、单位与子命令；缺少必需条件时向用户确认。
3. 字符串形式的数组和 JSON 参数按工具 schema 的格式填写。不要自行推导算法结果来替代调用，也不要改写工具返回的数值。
4. 工具返回错误时检查错误码与参数，最多修正一次；不要把失败调用包装成成功结果。文件型工具的路径受 MCP 数据目录限制，生成文件仍保存在服务器侧。
5. 回答计算题时给出所用工具、关键输入和结果。训练题要求用 <answer> 标签包住从实际工具结果准确摘录的 JSON 字段；大数组可只摘录前几项。产品回答可在引用结果后补充简短解释。

本技能只优化选择、参数及回答纪律；计算真值由 MCP 工具提供。不要在技能正文维护 144 个工具的第二份名单，目录以 MCP tools/list 与注册表为准。
