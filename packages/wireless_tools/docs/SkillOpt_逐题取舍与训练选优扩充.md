## 新增训练与选优题

新增 A01–A28 共 **28 题**：train 17、selection 11、holdout 0。每个注册产品领域都补了训练题和选优题。A25 用 Hamming 编码结果驱动解码；A26 用 WLAN BCC 编码结果驱动解码；A28 顺序创建蓝牙仿真会话、节点并列出对象。

| 领域 | 新增 train | 新增 selection | 覆盖重点 |
|---|---|---|---|
| LTE | A01、A02 | A03、A27 | TBS、调制、Gold 序列、层映射 |
| 5G | A04、A05 | A06 | 层映射、CRC11、PDCCH |
| WLAN | A07、A08 | A09、A26 | BCC、Golay、包检测、编解码传值 |
| Bluetooth | A10、A11 | A12 | GAP、ATT、BR/EDR 跳频 |
| Communications | A13、A14、A25 | A15 | 多位整数误码、Hamming、16QAM |
| Wireless Network | A16、A17 | A18 | 固定随机种子的游走、航点和布点 |
| Workflow | A19、A20 | A21 | QoS 建议、资源分配、失败验证 |
| Helper | A22、A23 | A24、A28 | 聚合工具子命令；蓝牙会话对象流程 |

Helper 与独立工具存在重叠。A22/A23/A24 显式点名 Helper 子命令，只评估该入口的调用契约；不能据此证明自然语言场景下应优先选择 Helper。A28 检查会话 API 的有序调用。随机仿真题固定种子，本地重复调用结果一致。

## 校验结果与使用边界

重建命令：在仓库根目录运行 .\.venv-skillopt\Scripts\python.exe -X utf8 -m scripts.build_curated_skillopt_draft --overwrite。

当前草案为 **71 题：train 28、selection 19、holdout 24**，实际完成 79 次本地 MCP 参考调用。三组均覆盖八个注册产品领域；selection 各领域至少 2 题。数据通过 reviewed_cases 的格式、分组、跨组近似模板扫描和本地 MCP 复算，并已由 freeze-draft 冻结到 skillopt_data/experimental-001。磁盘源题仍为 draft，未调用 freeze-reviewed、未启动 DeepSeek 训练，也未使用 holdout 挑选技能。train 与 selection 的离线模拟分别为 28/28、19/19。

跨组扫描将数字归一化后比较同一工具路线的题面，阈值为 0.85；它能拦住明显的数字替换模板，不能证明没有语义重叠。D10 与 D06 均为 NR MCS 表查询，但表类型和必答字段不同，归一化题面相似度约 0.725，保留为待观察的泛化题。后续若发现它使 holdout 高估能力，应在**下一版新题集**中替换，不能看过本版 holdout 成绩后修改本版来重新宣称独立验收。

该规模可用于下一轮小规模训练和诊断，但每个领域的题数仍少，且全是同一项目依据工具文档设计的专家题。正式发布前仍需核实网站产品用途、文件交付、题目来源权限；获得授权且脱敏的用户题后，应单独加入未来冻结集并保留来源标记。
