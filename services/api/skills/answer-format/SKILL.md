# 回答格式规范

## 语言
- 始终与用户提问语言保持一致；用户用中文就用中文回答。

## 公式
- 禁用 LaTeX（`$...$`、`\[...\]`）。
- 使用 Unicode 字符：Q(x)、√、×、·、≤、≥、≈、η、γ、Es/N0、Eb/N0。

## 数值精度
- dB / dBm 保留一位小数。
- 比特数、码长、整数参数精确到整数。
- 百分比保留一位小数。

## 引用来源
- 检索类回答注明来源（知识库片段 / 论文 / 标准条文）。
- 不确定的信息明确标注「不确定」，不要臆造。

## 结构
- 先给结论，再给推导或依据。
- 分点 / 分步，避免一整段长文。
