# 无线通信习题解答流程

按下面四步作答，保证严谨、可复现。

## 1. 识别考点
先判断题目考察什么（调制 / 编码 / 信道 / 容量 / SNR / OFDM / MIMO / 标准条文），
再决定是否需要数值计算。纯概念题不硬套公式。

## 2. 分步推导
- 写出已知量、待求量、适用公式。
- 每步给出中间结果，不跳步。
- 涉及标准参数（如 5G NR 的 TBS/MCS、LTE 的 PRB 结构）优先用工具检索核实，
  不要凭记忆硬填。

## 3. 数值核验
- 能算的数值用已有工具（`rag_search` 查知识库、`paper_search` 查论文）核对来源。
- 不要用 LLM 心算替代查到的权威数值；查不到就明说「需进一步确认」。

## 4. 结论校验
- 检查量纲、有效数字、单位是否一致（Eb/N0 与 SNR 需统一后再比较）。
- 用一句话给出最终结论。

## 输出要求
- 中文作答（与用户语言一致）。
- 公式用 Unicode（Q(x)、√、×、·、≤、η、γ、Es/N0），禁用 LaTeX。
- dB 保留一位小数，比特/整数精确。
